# 🏃‍♂️ Rastreador de Distancia Web

Un proyecto sencillo y visual para contar la distancia recorrida en metros y kilómetros utilizando botones interactivos de inicio y fin. Ideal para aprender las bases de desarrollo web.

## 🚀 Características
* **Botón Empezar:** Inicia el contador y simula el movimiento sumando metros cada segundo.
* **Botón Terminar:** Detiene el recorrido y muestra un resumen de la distancia total.
* **Cálculo automático:** Convierte instantáneamente los metros a kilómetros con decimales.

## 🛠️ Tecnologías utilizadas
* **HTML5:** Estructura de la pantalla y los botones.
* **CSS3:** Diseño limpio, moderno y responsivo.
* **JavaScript:** Lógica del cronómetro y operaciones matemáticas.
